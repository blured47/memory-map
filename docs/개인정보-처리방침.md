# Memory Map 개인정보 처리방침

시행일: 2026년 11월 27일

Memory Map(이하 "앱")은 사용자가 직접 켠 서버에 만남 기록을 저장하는 개인용 앱이다. 개발자는 사용자의 기록을 받거나 보관하는 서버를 운영하지 않는다.

## 1. 처리하는 정보

| 정보 | 입력 방법 | 저장 위치 |
|---|---|---|
| 친구 이름, 관계, 생일, 메모, 연락 주기 | 사용자가 직접 입력 | 사용자가 설정한 서버 |
| 만남 날짜·시각, 장소 이름, 좌표, 메모 | 사용자가 입력하거나 사진에서 읽음 | 사용자가 설정한 서버 |
| 사진 | 사용자가 고른 사진 | 사용자가 설정한 서버 (위치 등 EXIF 정보는 지우고 WebP로 저장) |
| AI가 메모에서 정리한 관심사·추천·질문·기념일 | 서버가 메모를 분석해 생성 | 사용자가 설정한 서버 |
| 서버 주소, 접근 토큰, 화면 설정(그룹 순서, 알림 기준) | 사용자가 입력 | 이 기기 |

## 2. 기기 권한

| 권한 | 목적 | 거부할 때 |
|---|---|---|
| 사진 보관함 | 기록할 사진을 고르고, 사진에 저장된 촬영 위치·시각을 읽는다 | 사진 없이 직접 기록할 수 있다 |
| 위치 (앱 사용 중) | 지도에 현재 위치를 표시한다. 위치는 저장하거나 전송하지 않는다 | 내 위치 버튼만 쓸 수 없다 |
| 로컬 네트워크 | 같은 와이파이에 있는 서버에 연결한다 | 서버에 연결할 수 없다 |

## 3. 외부로 전달되는 정보

- **카카오(지도, 장소 검색)**: 지도를 표시하기 위해 기기가 카카오 지도 서버에 접속한다. 장소를 검색하거나 사진 위치 근처 장소를 찾을 때 검색어와 좌표가 서버를 거쳐 카카오 로컬 API로 전달된다. 카카오의 처리는 카카오 개인정보 처리방침을 따른다.
- **AI 메모 정리**: 메모는 서버 컴퓨터에서 실행되는 로컬 AI(Ollama)로만 보내며, 인터넷의 외부 AI 서비스로 보내지 않는다.
- 위 경우 외에는 정보를 제3자에게 제공하거나 광고·분석 목적으로 수집하지 않는다.

## 4. 보관과 삭제

- 기록은 사용자가 지울 때까지 사용자의 서버에 보관된다.
- 만남을 지우면 그 만남의 사진과 AI 정리 결과도 함께 지워진다.
- 친구를 지우면 휴지통으로 옮겨지고 30일 뒤 완전히 지워진다. 휴지통에서 바로 영구 삭제할 수도 있다.
- 기록에 붙이지 않은 채 남은 사진은 하루가 지나면 지워진다.
- 앱을 지우면 기기에 저장한 서버 주소·토큰·화면 설정이 함께 지워진다. 서버의 기록은 서버 컴퓨터의 `data/` 폴더를 지워 삭제한다.

## 5. 보안

- 서버에 접근 토큰(`MEMORYMAP_API_TOKEN`)을 설정하면 같은 토큰을 가진 앱만 기록을 읽고 쓸 수 있다.
- 서버와 앱 사이 통신은 같은 와이파이 안에서 암호화되지 않은 HTTP로 이루어진다. 공용 와이파이에서는 서버를 켜지 않는 것을 권장한다.
