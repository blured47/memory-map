# 앱스토어 출시 점검표

작성일: 2026-11-27

코드에서 고칠 수 있는 항목은 처리했다. 남은 항목은 **구조 결정**, **계정·비용**, **실기기 확인**이 필요해 코드만으로는 끝낼 수 없다.

## 1. 이번에 처리한 항목

### 서버
- [x] 접근 토큰(선택): `MEMORYMAP_API_TOKEN` 을 설정하면 토큰이 맞는 요청만 받는다. 사진은 `?token=` 으로도 받는다
- [x] SQLite WAL 모드 + busy_timeout: AI 분류처럼 오래 걸리는 요청 중에도 저장이 막히지 않는다
- [x] AI 분류 중 메모가 바뀌면 옛 결과로 덮어쓰지 않고 409를 돌려준다. 만남이 지워졌으면 404
- [x] AI 분류 중에는 DB 연결을 붙잡지 않는다
- [x] 기록을 취소해 버려진 사진은 하루 뒤 자동 삭제, 만남을 지우면 사진도 삭제
- [x] 연락 주기 최대값(3650일) 검증
- [x] 테스트 11개 추가 (총 51개 통과)

### 앱
- [x] 서버 설정 화면: 서버 주소·토큰을 앱에서 입력하고 연결을 확인한다. 와이파이가 바뀌어도 다시 빌드할 필요가 없다
- [x] 서버 연결 실패 시 지도 위에 이유와 설정으로 가는 안내를 띄운다
- [x] 분류 중에 메모를 또 고치면 끝난 뒤 새 메모로 다시 분류한다 (전에는 조용히 무시됐다)
- [x] 앱으로 돌아오면 연락 알림과 만남 목록을 새로 불러온다
- [x] 연락 알림 기준 비율을 기기에 저장한다
- [x] 앱 아이콘(1024×1024, 투명 없음) 추가
- [x] 쓰지 않는 권한 문구(항상 위치, 동작 감지) 제거, 사진 권한 문구 통일
- [x] `ios.buildNumber`, Android 패키지 이름 정리
- [x] 아이콘 글꼴을 Ionicons만 포함해 번들 크기 축소 (글꼴 16개 → 1개)
- [x] Expo SDK 권장 패키지 버전으로 맞춤 (`npx expo install --check` 통과)
- [x] 아이콘 버튼에 VoiceOver 이름(accessibilityLabel) 추가
- [x] 개인정보 처리방침 작성 (`docs/개인정보-처리방침.md`)
- [x] 서버 설정: 연결에 실패하면 저장 전에 한 번 묻는다 (전에는 실패해도 바로 닫혀 이유를 볼 수 없었다)
- [x] 서버 주소에 포트를 안 적으면 `:8000` 을 붙인다 (`192.168.0.10` → `http://192.168.0.10:8000`)
- [x] 기록 작성 중 바깥을 눌러도 바로 닫지 않고 그만둘지 묻는다
- [x] 연락할 사람 목록에서 이름을 누르면 그 친구 화면이 열린다
- [x] AI 분류 중에도 만남을 지울 수 있다 (분류 결과는 버려진다)
- [x] 지도 오류 안내가 서버 연결 안내와 겹치지 않게 아래로 옮겼다
- [x] ESLint(정의 안 된 변수, Hook 규칙) 검사 오류 0개

## 2. 출시를 막는 항목 (결정 필요)

### 2-1. 심사자가 앱을 쓸 수 없는 구조 — 가장 큰 문제

앱은 사용자가 자기 Mac에서 켠 서버에 같은 와이파이로 붙어야 동작한다. 애플 심사자는 이 서버에 접속할 수 없으므로 심사 지침 **2.1 (앱 완성도)** 로 거절될 가능성이 높다. 서버를 직접 설치해야 하는 앱은 **4.2 (최소 기능)** 로도 지적받을 수 있다.

| 방법 | 내용 | 작업량 |
|---|---|---|
| A. 데모 서버 | 클라우드에 HTTPS 서버를 띄우고 심사 메모에 주소·토큰을 적는다. 앱의 ATS 설정은 지금 로컬 네트워크 HTTP만 허용하므로 HTTPS 주소여야 한다 | 중간 (서버 호스팅·도메인·비용) |
| B. 기기 안 저장 | 서버 없이 기기 안 DB(expo-sqlite)에 저장하고, AI 정리는 기기 안 모델이나 선택 기능으로 바꾼다 | 큼 (데이터 계층 전체 재작성) |
| C. 출시하지 않음 | 9주차 회의 결정대로 TestFlight·Expo Go로 시연만 한다 | 없음 |

9주차 회의록에 "앱스토어 출시와 클라우드 배포는 하지 않음"으로 결정돼 있으므로, 출시하려면 팀 합의가 먼저 필요하다.

### 2-2. 계정·비용
- [ ] Apple Developer Program 가입 (연회비 99달러, 팀 대표 계정)
- [ ] 번들 ID `io.github.blured47.memorymap` 을 그 계정에 등록
- [ ] 카카오맵·로컬 API의 앱 서비스 이용 조건과 하루 사용량 한도 확인 (확인하지 않았다)

### 2-3. 스토어 등록 자료
- [ ] 개인정보 처리방침을 공개 웹 주소로 올리기 (예: GitHub Pages). 앱스토어에 URL을 넣어야 한다
- [ ] App Store Connect의 개인정보 라벨 작성. 카카오 SDK가 수집하는 항목은 카카오 문서를 확인해 적어야 한다
- [ ] 스크린샷 (6.9인치 아이폰 필수 크기), 앱 설명, 키워드, 지원 URL

## 3. 실기기에서 확인할 항목

시뮬레이터와 자동 테스트로는 확인하지 못했다.

- [ ] 새 아이콘이 홈 화면에 제대로 보이는지 (`npx expo prebuild --clean` 후 빌드해야 `ios/` 에 반영된다)
- [ ] 서버 설정 → 연결 확인 → 저장 후 지도·사진 마커가 새 서버에서 불러와지는지
- [ ] 토큰을 설정한 서버에서 지도 사진 마커와 만남 사진이 보이는지
- [ ] 사진 EXIF 위치·시각 읽기 (README 3단계 "실기기 확인 필요")
- [ ] 메모 저장 직후 다시 고쳤을 때 AI 카드가 새 메모 기준으로 바뀌는지
- [ ] 권한 거부 시 흐름 (사진, 위치, 로컬 네트워크)

## 4. 빌드 명령

```bash
cd frontend
npx expo prebuild --clean      # app.json 변경(아이콘·권한 문구)을 ios/ 에 반영
npx expo run:ios --device      # 연결한 아이폰으로 확인
```

앱스토어용 빌드는 Xcode에서 Product > Archive 하거나 EAS Build(`eas build -p ios`)를 쓴다. 둘 다 Apple Developer 계정이 필요하다.
